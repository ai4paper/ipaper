# Changelog

All notable changes to this project will be documented in this file.

## [0.1.1]

- Chat: Fixed draft restore stealing editor focus when returning to a conversation. (@isomoes)
- Chat: Kept manual scroll override active until the feed is returned to the bottom. (@isomoes)
- Sidebar: Restored hover actions without blocking tree control interactions. (@isomoes)
- Web: Added package publish workflow and release cleanup for distribution. (@isomoes)
- UI: Added the GitHub Dark Colorblind theme. (@isomoes)

## [0.1.0]

- Chat: Fixed bottom-follow cancellation for extension-driven scrolling so Surfingkeys-style `j`/`k`/`u`/`d` navigation can reliably break pin-to-bottom behavior. (@isomoes)
- Initial IPaper monorepo setup for the web and UI runtimes. (@isomoes)
